# EcoMarket Backend

API RESTful de **EcoMarket**, el buscador de comercio local y sostenible.
Proyecto del curso 1ASI0705 Arquitectura de Aplicaciones Web (UPC), Grupo 06.

## Requisitos

- JDK 21 o superior.
- PostgreSQL con la base de datos `ecomarket_db` (se crea desde pgAdmin 4).

## Ejecutar

```bash
./mvnw spring-boot:run
```

En Windows: `mvnw.cmd spring-boot:run`.
